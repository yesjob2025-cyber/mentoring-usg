# 교육사업 준비 자동화 (Google Apps Script)

별도의 서버나 앱 없이 **Google Drive 안에서만** 도는 프로세스입니다.
사업이 확정되면 관리용 구글 시트 메뉴에서 클릭 한 번으로, **유형(온라인/오프라인/박람회)과
시작일에 맞춘 준비 체크리스트 구글 시트**가 Drive에 자동 생성·공유됩니다.

예스잡 운영 체크리스트(온라인 멘토링 · 오프라인 연수/경진대회 · 박람회)의 공통 구조를
템플릿으로 표준화했습니다.

---

## 무엇이 자동화되나

1. **유형별 준비 항목 자동 생성** — 온라인/오프라인/박람회에 맞는 준비 항목이 카테고리별로 펼쳐짐
   (사업내용 · 계약 · 섭외 · 홍보물 · 행사준비 · 연수시설 · 학생관리 · 정산 …)
2. **D-day 마감일 자동 계산** — 교육/행사 시작일 기준으로 각 항목의 마감일이 날짜로 환산
   (예: 강사 섭외 = D-30, 교재 제작 = D-7). `D-day` 열은 오늘 기준 남은 일수를 실시간 표시
3. **상태 관리** — `상태` 열 드롭다운(할 일/진행중/완료), 완료는 초록, **마감 지난 미완료는 빨강**,
   **임박(3일 이내)은 노랑**으로 자동 강조
4. **예산/비용 집계** — 예상비용·실제비용 합계, `요약` 시트에 진행률·지난 마감·비용 합계 표시
5. **자동 공유** — 지정한 Drive 폴더에 저장 + 입력한 이메일로 편집 권한 공유 후 링크 반환

생성되는 시트 구조 (기존 xlsx와 동일한 컬럼):

```
구분 | 마감일 | D-day | 세부 진행 | 강사/업체 연락처 | 준비담당 | 상태 | 비고 | 예상비용 | 실제비용
```

## 설치 (5분, 붙여넣기 방식 — 권장)

1. **관리용 시트 만들기**: [sheets.new](https://sheets.new) 로 빈 구글 시트를 하나 만듭니다.
   (이 시트가 "리모컨" 역할 — 실제 체크리스트는 매번 새 파일로 생성됩니다.)
2. 상단 메뉴 **확장 프로그램 → Apps Script** 클릭 → 스크립트 편집기가 열립니다.
3. 이 폴더의 파일 내용을 편집기에 그대로 옮깁니다.
   - `Code.gs` → 기본 `Code.gs`에 붙여넣기
   - **＋** 버튼으로 스크립트 파일 추가 → 이름 `Templates` → `Templates.gs` 내용 붙여넣기
   - **＋** 버튼으로 HTML 파일 추가 → 이름 `Dialog` → `Dialog.html` 내용 붙여넣기
   - (선택) 좌측 ⚙️ **프로젝트 설정 → "appsscript.json 매니페스트 파일 표시"** 체크 후
     `appsscript.json` 내용으로 교체 (권한 범위 지정)
4. 저장(💾) 후, 편집기에서 `createSampleChecklist` 함수를 한 번 **실행** → 권한 승인 팝업에서 허용.
   (내 Drive/시트에 접근하는 권한입니다. 최초 1회만.)
5. 관리용 시트로 돌아가 **새로고침(F5)** → 상단에 **📋 교육사업 준비** 메뉴가 생깁니다.

> **clasp로 배포하고 싶다면**: `.clasp.json.example`을 `.clasp.json`으로 복사하고
> `scriptId`를 채운 뒤 `clasp push`. (`npm i -g @google/clasp`, `clasp login` 필요)

---

## 사용법

1. 관리용 시트에서 **📋 교육사업 준비 → ＋ 새 사업 체크리스트 생성**
2. 입력창에 사업명·유형·시작일(필수)과 기관·담당자·예산·공유 이메일 등을 입력
3. **체크리스트 생성** → 새 구글 시트가 만들어지고 링크가 표시됩니다. 링크를 눌러 이어서 작업.

### 저장 폴더 지정 (선택)

**📋 교육사업 준비 → 📂 저장 폴더 지정** 에서 Drive 폴더 URL/ID를 넣으면,
이후 생성물이 모두 그 폴더에 저장됩니다. (미지정 시 "내 드라이브" 루트)

## 템플릿 수정

준비 항목·마감일(D-day)을 바꾸려면 `Templates.gs`만 편집하면 됩니다.

```js
{ c: '사전세팅', t: '강사 섭외', d: -30 }   // c=구분, t=항목명, d=시작일 기준 마감(음수=이전)
```

- 공통 항목: `TPL_COMMON`
- 온라인 전용: `TPL_ONLINE` · 오프라인 전용: `TPL_OFFLINE` · 박람회 전용: `TPL_EXPO`
- 카테고리 표시 순서: `CATEGORY_ORDER`

---

## 파일 구성

| 파일 | 역할 |
|------|------|
| `Code.gs` | 메뉴, 입력 처리, 시트 생성·서식, D-day 계산, Drive 저장·공유 |
| `Templates.gs` | 유형별 준비 항목 템플릿 (여기만 고치면 항목/일정 변경) |
| `Dialog.html` | 사업 정보 입력 폼 |
| `appsscript.json` | 실행 런타임·권한 범위(매니페스트) |
| `.clasp.json.example` | clasp 배포용 설정 예시 |

---

## 참고

- 데이터는 각각의 구글 시트 파일에 남습니다(중앙 DB 없음). 사업 1건 = 시트 파일 1개.
- 권한 범위: 스프레드시트/드라이브 접근, 다이얼로그 표시, 이메일 확인. 모두 본인 계정 내에서 동작합니다.
